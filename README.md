# Бот группы L2Hub в Telegram

Сам пишет в группу `l2hub`, по темам:

| Тема | Что пишет | Откуда берёт |
|---|---|---|
| 🚀 Обновления (`TG_TOPIC_UPDATES`) | «Вышла L2Hub v0.5.180» и 3–7 пунктов, что нового | теги и `CHANGELOG.md` публичного `kraffty4/L2Hub`; пересказ — DeepSeek |
| 🔧 Система (`TG_TOPIC_SYSTEM`) | новости моста и смены статусов задач («hunter-rift: план → в работе (kraffty)») | `git pull` закрытого `kraffty4/L2Hub-bridge` |
| 📦 Наработки (`TG_TOPIC_WORK`) | архив и текст к нему | папка `outbox/`: пара `тема.zip` + `тема.md` |

На сообщения в группе бот не отвечает и ничего не читает: только постит. С ботами Сергея (Codex) не пересекается.

Работает на этом компьютере по расписанию. В облаке GitHub не получится: мост закрытый (облаку понадобился бы токен с доступом ко всем твоим закрытым репозиториям), а архивы появляются здесь, на диске. Выключенный компьютер ничего не теряет: что уже отправлено, бот помнит в `state/seen.json` и после включения допишет пропущенное.

## Что сделать один раз

1. **Бот.** В Telegram у @BotFather: `/newbot`, имя и `username` с окончанием `bot`. BotFather выдаст токен.
2. **Темы в группе** включает её админ (Сергей): «Изменить группу» → «Темы». Создать темы: Обновления, Система, Наработки (и людям — Обсуждение, Идеи, Ошибки). После включения тем у группы **меняется chat_id**, Сергею нужно обновить его у своего Codex.
3. Сергей добавляет бота в группу. Права админа не нужны.
4. Файл `.env` рядом со скриптом (образец — `.env.example`), токены вписываешь **сам**:
   ```
   TELEGRAM_BOT_TOKEN=...
   LLM_API_KEY=...            # ключ DeepSeek, тот же, что у новостей VALOMAFIA
   TG_CHAT_ID=-100...
   TG_TOPIC_UPDATES=...
   TG_TOPIC_SYSTEM=...
   TG_TOPIC_WORK=...
   ```
   `chat_id` и id тем: напиши по сообщению в каждую из трёх тем, потом `python l2hub_tg.py topics`.
5. Первый запуск — `python l2hub_tg.py init`: бот запомнит текущую версию и состояние моста и не будет вываливать в группу всю историю.
6. Проверка без отправки: `python l2hub_tg.py watch --dry-run`.
7. Расписание — Планировщик Windows, раз в 10 минут: `run.cmd`.

## Как Claude выкладывает наработки

Закончил тему — кладёт в `outbox/` архив и текст с одним именем (`hunter-rift.zip` + `hunter-rift.md`). Первый абзац `.md` становится подписью к файлу. На следующем запуске бот выкладывает их в «Наработки» и переносит в `outbox/sent/`.

## Требования

Python 3.12+ и `requests` (`pip install -r requirements.txt`), `git` с доступом к мосту (клон в `D:\Games\L2Hub-bridge`, путь меняется переменной `BRIDGE_DIR`).
